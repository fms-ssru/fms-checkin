เลือกหมู่เรียนที่จะเพิ่มเข้า (ไม่บังคับ)

เลือกไว้ก่อน แล้วนำเข้ารายชื่อด้วยวิธีไหนก็ได้ด้านล่าง ทุกคนจะถูกใส่เข้าหมู่นี้ให้อัตโนมัติ

1) วางรายชื่อด้วยมือ

รูปแบบ: รหัสนักศึกษา,ชื่อ-นามสกุล หรือ รหัสนักศึกษา,ชื่อ-นามสกุล,หมู่เรียน (ถ้าใส่หมู่เรียนมาด้วย จะแยกหมู่ให้อัตโนมัติ ต้องเลือก "รายวิชา" ด้านบนไว้ก่อน) บรรทัดละ 1 คน

2) อัปโหลดไฟล์ Excel (.xlsx)

เลือกคอลัมน์รหัสนักศึกษาและชื่อในหน้าจอถัดไป (แถวแรกเป็นหัวตารางก็ได้ ระบบข้ามให้อัตโนมัติ)

3) ดึงจาก Google Sheets

ใน Google Sheets: File → Share → Publish to web → เลือกชีต → Comma-separated values (.csv) → วางลิงก์ที่ได้ตรงนี้

ยืนยันคอลัมน์ก่อนนำเข้า

เลือกว่าคอลัมน์ไหนคือข้อมูลอะไร (ดูตัวอย่างข้อมูลจริงประกอบ) ระบบเดาให้เบื้องต้นแล้ว เช็คให้ถูกต้องก่อนกดยืนยัน

ถ้าเลือกคอลัมน์หมู่เรียน ระบบจะแยกหมู่ให้อัตโนมัติตามค่าที่เจอในคอลัมน์นั้น (สร้างหมู่ใหม่ให้เองถ้ายังไม่มี) — ต้องเลือก "รายวิชา" ที่ด้านบนของหน้าไว้ก่อนด้วย

ใส่รหัสของคนที่เพิ่มไว้แล้วอีกครั้ง + เลือกหมู่เรียนใหม่ เพื่อ "ย้ายหมู่" ได้เลย
