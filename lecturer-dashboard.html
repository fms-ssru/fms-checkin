สรุปการเข้าเรียน

ภาพรวมทุกรายวิชาที่สอน

แนวโน้มการเข้าเรียนรายคาบ

สัดส่วนสถานะการเข้าเรียน

เปรียบเทียบเปอร์เซ็นต์เข้าเรียนแต่ละวิชา

% เข้าเรียน = (จำนวนที่เช็คชื่อ มา/สาย) ÷ จำนวนรายชื่อทั้งหมด · "ขาด" นับรวมทั้งคนที่ไม่เช็คชื่อเลยและคนที่อาจารย์ปรับสถานะเป็นขาดเอง

จัดการรายชื่อนักศึกษา

กำลังโหลด…

1) วางรายชื่อด้วยมือ

รูปแบบ: รหัสนักศึกษา,ชื่อ-นามสกุล,กลุ่มเรียน บรรทัดละ 1 คน (กลุ่มเรียนใส่หรือไม่ใส่ก็ได้)

2) อัปโหลดไฟล์ Excel (.xlsx)

คอลัมน์ A=รหัสนักศึกษา, B=ชื่อ-นามสกุล, C=กลุ่มเรียน (แถวแรกเป็นหัวตารางก็ได้ ระบบจะข้ามให้อัตโนมัติถ้ารหัสไม่ใช่ตัวเลข)

3) ดึงจาก Google Sheets

ใน Google Sheets: File → Share → Publish to web → เลือกชีต → Comma-separated values (.csv) → วางลิงก์ที่ได้ตรงนี้

ยืนยันคอลัมน์ก่อนนำเข้า

เลือกว่าคอลัมน์ไหนคือข้อมูลอะไร (ดูตัวอย่างข้อมูลจริงประกอบ) ระบบเดาให้เบื้องต้นแล้ว เช็คให้ถูกต้องก่อนกดยืนยัน
